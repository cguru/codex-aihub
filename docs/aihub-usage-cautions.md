# AI Hub 연동 및 데이터 이용 주의사항

이 문서는 `codex-aihub` 사용자가 알아야 할 운영상 주의사항을 정리합니다.
특정 시점의 답변이나 안내문을 그대로 옮긴 것이 아니며, 최신 AI Hub 정책과
개별 데이터셋의 이용 조건이 항상 우선합니다.

## 엔드포인트 안정성

이 플러그인이 사용하는 AI Hub 엔드포인트는 규격과 지속성이 보장된 공개
API가 아닙니다. 사전 고지 없이 주소, 요청 방식, 응답 형식이 변경되거나
서비스가 중단될 수 있습니다. 이 경우 플러그인이 일시적으로 또는 계속
동작하지 않을 수 있습니다.

## 데이터 접근

- 정식 데이터 다운로드에는 각 이용자 본인의 데이터 사용 신청·승인과 개인
  API 키가 필요합니다.
- 이 플러그인은 승인 절차를 우회하거나 다른 사람의 승인 또는 API 키를
  대신 사용하지 않습니다.
- 승인 여부가 확인되지 않으면 다운로드를 진행하지 않고 AI Hub에서 데이터
  사용 신청을 먼저 하도록 안내합니다.
- 웹사이트에서 별도로 제공하는 경량 샘플과 API 키를 이용한 정식 데이터
  다운로드는 서로 다른 절차로 취급합니다.
- 사용자가 명시적으로 샘플을 요청하지 않으면 샘플을 대신 받지 않습니다.

## 데이터 이용과 공유

이 저장소의 MIT 라이선스는 플러그인의 독자적인 소스 코드와 프로젝트
문서에만 적용됩니다. AI Hub에서 받은 데이터, 설명서, 모델 및 데이터 제공
기관이 권리를 가진 자료에는 적용되지 않습니다.

다운로드한 데이터에는 AI Hub의 최신 이용정책과 개별 데이터셋의 조건이
적용됩니다. 제3자 제공, 양도, 재배포, 국외 이용·반출, 이용 목적, 출처
표기 등에 제한이나 별도 절차가 있을 수 있습니다. 다운로드 전에 조건을
확인하고, 가공 데이터·학습 모델·서비스·연구 결과를 외부에 공개하거나
공유하기 전에도 다시 확인해야 합니다.

플러그인을 설치하거나 사용하는 것만으로 데이터에 대한 추가 권리를 얻거나
AI Hub 또는 NIA의 승인·보증을 받는 것은 아닙니다.

## 프로젝트 운영 원칙

- 기능은 TypeScript로 독립 구현하며 AI Hub의 소스 코드, JAR 또는
  `aihubshell` 실행 파일을 복제·재배포하지 않습니다.
- 자동화 테스트에는 가짜 키와 합성 응답만 사용합니다.
- 실제 다운로드 데이터, 테스트용 학습 프로그램, 학습 모델과 그 밖의 실험
  산출물은 Git 기록과 배포 패키지에 포함하지 않습니다.
- 승인 우회나 데이터셋 재배포를 돕는 기능을 만들지 않습니다.

## API 키 노출 시

AI Hub의 공개 안내에는 API 키 발급 절차가 있지만 기존 키를 사용자가 직접
폐기하는 절차는 확인되지 않습니다. 새 키를 추가 발급했다고 해서 노출된
기존 키가 자동으로 무효화됐다고 가정하면 안 됩니다.

키가 채팅, 로그, 화면 캡처 또는 공개 스레드에 나타났다면 해당 내용을
공개하지 말고 불필요한 로컬 복사본을 제거하세요. 키를 공개 이슈나 문의
게시물에 다시 붙여 넣지 말고, `aihub@aihub.kr`로 기존 키의 중지·폐기
가능 여부를 문의하세요.
